第 39 课 · 位运算技巧

位运算是把一个整数看成一排开关（二进制的每一位是 0 或 1），一次性对所有开关做同样的操作。面试里常考的就几招：异或让成对的数抵消、n & (n - 1) 去掉最低位的 1、用一个整数的各位表示“选了哪些东西”。

开始前要会：Python —— 整数运算（//、大整数）、推导式、enumerate、类（这里用 enum.Flag 写一个类）、in 背后的魔法方法；前面的课 —— 第 21 课 · 回溯（子集）、第 37 课 · 一维 DP（四步法）。位运算本身（&、|、^、<<、>>）是这一课第一次正式讲，从下面第一节开始。

五个运算符的直觉

先看 Python 里怎么写二进制：数字前加 0b 就是按二进制写的整数，0b1100 就是 12；中间可以加下划线方便看，0b1010_0001 等于 0b10100001。反过来，bin(12) 返回字符串 '0b1100'，用来打印看看每一位。

0b1100            # 12
0b1010_0001       # 161，下划线只是分隔，不影响值
bin(12)           # '0b1100'
12 & 10, 12 | 10, 12 ^ 10   # (8, 14, 6)，规则见下表

下面用 12（二进制 1100）和 10（二进制 1010）举例。每个运算都是一位一位分别算，各位之间互不影响（移位除外）。

运算规则直觉例子
a & b 与两位都是 1，结果才是 1“过滤”：只保留两边都开着的开关。常用来检查某一位是不是 11100 & 1010 = 1000（8）
a | b 或有一位是 1，结果就是 1“合并”：把开关打开。常用来设置某一位为 11100 | 1010 = 1110（14）
a ^ b 异或两位不同是 1，相同是 0“翻转”：b 里是 1 的位置，把 a 的那一位翻过来。自己异或自己是 01100 ^ 1010 = 0110（6）
a << k 左移整体往左挪 k 位，右边补 0乘以 2k0011 << 2 = 1100（3 → 12）
a >> k 右移整体往右挪 k 位，最右边 k 位丢掉除以 2k 向下取整，等于 a // 2**k1101 >> 1 = 0110（13 → 6）

还有一个取反 ~a：每一位都翻过来。在 Python 里整数没有固定位数，~a 的结果是 -a - 1，平时很少单独用，主要和 & 搭配“清掉某些位”（下面的实战和小招式里都会见到）。和 += 一样，这些运算也有 &=、|=、^= 的简写。

实战里怎么写：enum.Flag、bit_count、ipaddress

Python 业务代码里很少直接写 &、|，但位运算无处不在：权限和开关、子网掩码、用一个整数表示一个小集合。多数情况标准库已经包好了。

场景用什么代价
权限、开关、选项的组合enum.Flag：| 组合，in 判断，&= ~ 去掉O(1)，一个整数存下所有开关
数一个整数里有几个 1int.bit_count()（Python 3.10+）O(1)，C 实现
IP 在不在网段里、掩码是多少标准库 ipaddress底层就是 ip & 掩码 == 网段地址
元素不超过二三十个的集合（技能、选中的人）整数当集合（状态压缩）并、交是 O(1)；枚举所有子集 O(2n)
import ipaddress
from enum import Flag, auto

class Permission(Flag):
    READ = auto()        # 0b001
    WRITE = auto()       # 0b010
    DELETE = auto()      # 0b100

user = Permission.READ | Permission.WRITE
Permission.WRITE in user             # True，等价于 (user & WRITE) == WRITE
user &= ~Permission.WRITE            # 收回写权限，只剩 READ（~WRITE 是“除了写权限那一位，其余全是 1”）

(0b1010_0001).bit_count()            # 3：打开了 3 个功能开关

network = ipaddress.ip_network("192.168.1.0/24")
ipaddress.ip_address("192.168.1.77") in network                       # True
int(ipaddress.ip_address("192.168.1.77")) & int(network.netmask) == int(network.network_address)   # 同一件事

上面用到的三个标准库工具，用法就这么多：

  • enum.Flag：写一个继承它的类，每个成员是一个开关。auto() 自动给成员分配下一个 2 的幂（1、2、4……），所以每个成员正好占一位。成员之间可以用 |、&、~ 组合，a in b 判断“a 的开关 b 是不是全有”（Flag 替你实现了 __contains__）。
  • int.bit_count()：整数自带的方法，返回二进制里 1 的个数。直接对数字字面量调用时要加括号，写成 (0b101).bit_count()。
  • ipaddress：ip_address("…") 解析一个 IP，ip_network("…/24") 解析一个网段，in 判断 IP 在不在网段里，int(…) 把 IP 或掩码变成一个整数。

完整可运行的版本在 examples/bit_manipulation_in_practice.py（uv run examples/bit_manipulation_in_practice.py），里面还有一个状态压缩的例子：每个技能占一位，枚举所有“选人方案”的位掩码，找出技能覆盖全部需求的最小团队，用的正是本课题 4 的写法。

常用小招式

下面的 k 表示“第 k 位”，最右边是第 0 位。1 << k 就是“只有第 k 位是 1”的数，叫做掩码（mask）。

想做什么写法为什么
第 k 位是不是 1(number >> k) & 1把第 k 位挪到最右边，再只看最右边一位
把第 k 位设成 1number | (1 << k)和掩码“或”，那一位一定变成 1，其它位不变
把第 k 位清成 0number & ~(1 << k)~(1 << k) 除了第 k 位全是 1，“与”之后只有第 k 位被清掉
翻转第 k 位number ^ (1 << k)和 1 异或就是翻转，和 0 异或不变
判断奇偶number & 1最低位是 1 就是奇数
去掉最低位的 1number & (number - 1)见下面题 2，本课最重要的一招
只留下最低位的 1number & -number拓展了解，树状数组会用到（本课程不讲树状数组）

养成加括号的习惯。在 Python 里，& 比 == 优先级高，所以 number & 1 == 0 恰好是对的；但在 C、Java、JavaScript 里它会被理解成 number & (1 == 0)。另外移位比加减优先级低，1 << k - 1 是 1 << (k - 1)。写成 (number & 1) == 0、(1 << k) - 1 就不用记这些。

题 1：只出现一次的数字（LeetCode 136）

题意：数组里除了一个数只出现一次，其余每个数都恰好出现两次。找出只出现一次的那个。要求 O(n) 时间、O(1) 额外空间。

例子：[4, 1, 2, 1, 2]，1 和 2 都出现两次，返回 4。

普通做法为什么不满足要求：用字典数每个数出现几次，时间 O(n)，但要 O(n) 额外空间；先排序再看相邻的数，空间省了，但时间是 O(n log n)。

关键观察：异或有三个性质——

  • x ^ x = 0：每一位都和自己相同，全变成 0。
  • x ^ 0 = x：和 0 异或，每一位都不变。
  • 异或可以随意交换顺序、随意加括号（交换律、结合律），因为每一位都是独立地“数 1 的个数是奇数还是偶数”。

这个技巧怎么用上去：把所有数异或起来。因为顺序可以随便换，可以想象先把成对的数排到一起：4 ^ 1 ^ 2 ^ 1 ^ 2 = 4 ^ (1 ^ 1) ^ (2 ^ 2) = 4 ^ 0 ^ 0 = 4。成对的全部抵消成 0，剩下的就是只出现一次的那个。

def single_number(numbers):
    single = 0
    for number in numbers:
        single ^= number          # 成对的数异或后抵消成 0
    return single

# 实际项目里也常写成一行：functools.reduce(operator.xor, numbers, 0)
# reduce(函数, 序列, 初始值) 从初始值开始，拿函数依次“滚”过每个元素：((0 ^ 4) ^ 1) ^ 2 ...
# operator.xor(a, b) 就是 a ^ b，和预备课里 operator.itemgetter 是同一个模块

为什么是对的：看任意一位。出现两次的数在这一位上贡献了偶数个 1（要么 0 个，要么 2 个），异或的结果只看这一位上 1 的个数是奇是偶，偶数个 1 等于没有。所以每一位的结果，都只由只出现一次的那个数决定。

复杂度：O(n) 时间，O(1) 额外空间。

同一招的变体：丢失的数字（LeetCode 268）。0..n 里缺了一个数，数组里有其余 n 个。把 0..n 全部和数组里的数一起异或，出现两次的抵消，剩下的就是缺的那个。

题 2：n & (n - 1)：去掉最低位的 1

它在做什么：减 1 的时候，二进制从最低位开始借位：最低位的那个 1 变成 0，它右边的 0 全部变成 1，更高的位不变。再和原数“与”一下，变化过的那几位全部变成 0，更高的位保持原样。结果就是：原数去掉了最低位的那个 1。

十进制二进制
number121100
number - 1111011（最低位的 1 变 0，右边的 0 变 1）
number & (number - 1)81000（第 2 位的 1 被去掉了）

用法一：位 1 的个数（LeetCode 191）

题意：一个非负整数的二进制里有几个 1。例如 11 = 1011，有 3 个 1。

普通做法：一位一位地看（number & 1，然后右移），要循环“二进制的总位数”次，32 位整数就是 32 次。

用上这一招：反复执行 number &= number - 1，每次正好去掉一个 1，直到变成 0。去了几次，就有几个 1。循环次数等于 1 的个数，对“1 很少”的数特别快。

def count_one_bits(number):
    one_bit_count = 0
    while number:
        number &= number - 1      # 去掉最低位的 1
        one_bit_count += 1
    return one_bit_count

# 实际项目里直接用 number.bit_count()（Python 3.10+），这里手写是为了练 n & (n - 1)

用法二：2 的幂（LeetCode 231）

题意：判断一个整数是不是 2 的幂（1、2、4、8、16……）。

关键观察：2 的幂的二进制恰好只有一个 1（16 = 10000）。去掉这唯一的 1 之后就变成 0。反过来，有两个以上 1 的数，去掉最低位的那个后还剩别的 1，不是 0。

def is_power_of_two(number):
    return number > 0 and (number & (number - 1)) == 0

number > 0 不能省：0 没有任何 1，0 & -1 也等于 0，会被误判成 2 的幂；负数也不是 2 的幂。复杂度：O(1)。

题 3：比特位计数（LeetCode 338）

题意：给一个 limit，返回长度为 limit + 1 的列表，第 i 项是 i 的二进制里 1 的个数。

例子：limit = 5，0..5 的二进制是 0、1、10、11、100、101，返回 [0, 1, 1, 2, 1, 2]。

普通做法为什么慢：对每个数单独去数，是 O(limit × 位数)。

关键观察：这其实是一道一维 DP。i >> 1 是把 i 的最后一位去掉，它比 i 小，答案已经算过；i 比它多出来的只有最后一位 i & 1。

  1. 状态：one_bit_count[i] = i 的二进制里 1 的个数。
  2. 转移：one_bit_count[i] = one_bit_count[i >> 1] + (i & 1)。另一种写法用上题 2 的招式：one_bit_count[i] = one_bit_count[i & (i - 1)] + 1（去掉一个 1 之后的数更小，也算过了）。
  3. 初始值：one_bit_count[0] = 0。
  4. 遍历顺序：i 从 1 到 limit。

例如 5 = 101：5 >> 1 = 2 = 10，有 1 个 1；5 的最后一位是 1，所以 5 有 1 + 1 = 2 个 1。复杂度：O(limit)。

题 4：用位掩码枚举子集（LeetCode 78）

题意：列出一个数组（元素互不相同）的所有子集。第 21 课用回溯写过，这里换一种写法。

关键观察：n 个元素，每个元素“选或不选”，正好对应一个 n 位二进制数的每一位“1 或 0”。所以 0 到 2n − 1 这 2n 个整数，和 2n 个子集一一对应。这个整数就叫位掩码 bit_mask：第 k 位是 1，就表示选了 items[k]。

bit_mask二进制（第 2、1、0 位）items = [1, 2, 3] 的子集
0000[]
1001[1]
2010[2]
3011[1, 2]
5101[1, 3]
7111[1, 2, 3]
def subsets_by_bit_mask(items):
    all_subsets = []
    for bit_mask in range(1 << len(items)):          # 0 到 2^n - 1
        subset = [items[k] for k in range(len(items)) if (bit_mask >> k) & 1]
        all_subsets.append(subset)
    return all_subsets

# 只要子集、不需要位掩码时，标准库写法是（见预备课 itertools 一节）
# chain.from_iterable(combinations(items, size) for size in range(len(items) + 1))
# chain.from_iterable(很多个序列) 和 chain(*很多个序列) 一样，把它们首尾接起来

和回溯比：没有递归，代码更短；而且一个子集可以用一个整数表示，能当字典的键、能存进数组。所以状态压缩 DP（比如“已经访问过哪些城市”）都用位掩码。缺点是 n 不能太大，n = 20 时已经有一百万个子集。复杂度：O(n × 2n)。

怎么认出这类题

  • “其余都出现两次，找出现一次的”“找缺失的数”“要求 O(1) 额外空间”：想异或抵消。
  • “二进制里有几个 1”“2 的幂”“汉明距离”：想 n & (n - 1)。
  • “所有子集”而且 n 很小（一般 n ≤ 20），或者需要用一个数记住“哪些东西已经用过 / 访问过”：想位掩码。
  • “不用加减乘除”实现某个运算：想用异或做“不进位的加法”、用与和左移算进位。
  • 题目给的数据范围特别提到“32 位整数”“非负整数”，往往是在暗示位运算。

最容易错的地方

  • 负数：Python 的整数没有固定位数，负数在位运算里相当于左边有无穷多个 1。对负数执行 while number: number &= number - 1 永远停不下来。本课除了异或类的题，输入都是非负整数；遇到要求按 32 位处理负数的题，先 number &= 0xFFFFFFFF。
  • 2 的幂忘了判断 number > 0：0 会被误判成 True。
  • 优先级：不确定的时候一律加括号，尤其是从别的语言改写过来的代码。
  • 第 k 位从哪数起：最右边是第 0 位。1 << n 是 2n，枚举子集时 range(1 << n) 正好是 0 到 2n − 1。
  • 异或抵消只对“恰好出现偶数次”的数有效；出现三次的数不会被抵消（那是 LeetCode 137 的情况）。

自测

1. 为什么 number & (number - 1) 正好去掉最低位的 1？ 减 1 时从最低位借位：最低位的那个 1 变成 0，它右边的 0 全变成 1，更高的位不变。和原数“与”时，最低位的 1 那一位是 1 & 0 = 0，它右边那些位是 0 & 1 = 0，更高的位是自己和自己“与”，不变。所以只有最低位的 1 被去掉了。
2. 一个数组里，除了一个数出现一次，其余都出现两次。如果用求和来做（2 × 所有不同的数之和 − 数组之和）可以吗？和异或比有什么缺点？ 可以算对，但要先找出“所有不同的数”，这需要一个集合，额外空间就是 O(n) 了。另外在有固定位数的语言里，求和还可能溢出。异或既不用额外空间，也不会溢出。
3. 比特位计数里，为什么 one_bit_count[i >> 1] 一定已经算好了？ i ≥ 1 时 i >> 1 = i // 2 < i，而我们是从小到大填表的，比 i 小的下标都已经填过。这正是四步法第 4 步“遍历顺序要保证用到的状态已经算好”。
