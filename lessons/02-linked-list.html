第 2 课 · 链表

链表的每个节点只记两样东西：自己的值和下一个是谁。像寻宝游戏，每张纸条告诉你下一张在哪。

长什么样

head → 1→2→3→ None（tail 指向 3） 
class Node:
    def __init__(self, value, next=None):
        self.value = value
        self.next = next

节点不用排在一起，散落在内存的任何地方都行，靠 next 串起来。

和数组比一比

操作数组链表
按下标取第 i 个O(1)O(n)，只能从头一个个数
头部插入 / 删除O(n)O(1)
尾部插入均摊 O(1)O(1)（前提是记着 tail）

一句话：数组擅长随机访问，链表擅长在已知位置增删。

头部插入：两步，顺序不能反

0→1→2→None 
node = Node(0, self.head)   # ① 新节点先指向旧的头
self.head = node            # ② 再把 head 挪到新节点

如果先挪 head，旧的头就找不到了。改指针之前，先想清楚谁会因此“失联”。

删除：要找的是“前一个”

单链表只能往后走。要删掉 2，得站在 1 上，让 1 跳过 2：

1⤼23 prev.next = prev.next.next

小技巧：哨兵节点。在 head 前面放一个假节点 dummy，这样删头节点和删中间节点就是同一种写法，不用单独判断。

反转：三个指针一起往前走

prev, cur = None, self.head
while cur:
    nxt = cur.next      # 先记住后面
    cur.next = prev     # 掉头
    prev = cur          # 两个指针一起前进
    cur = nxt

别忘了，反转之后 head 和 tail 要互换。

最容易错的三个地方

  • 链表变空的时候，head 和 tail 都要变回 None。
  • 删掉的正好是尾巴，tail 要退回到前一个节点。
  • 只有一个节点时，head 和 tail 是同一个节点。

测试会专门检查这三种情况。

练习

补全 dsa/linked_list.py。建议顺序：push_front → __iter__（用 yield）→ push_back → pop_front → find → remove → reverse。

uv run pytest tests/test_linked_list.py

自测

1. 为什么链表取第 i 个是 O(n)？ 节点不连续，没法算地址，只能从 head 开始沿着 next 走 i 步。
2. 有 tail 指针，为什么 pop_back（删尾巴）还是 O(n)？ 删掉尾巴以后，tail 要指向倒数第二个节点，可单链表没法往回走，只能从头找。双向链表就能做到 O(1)。
3. Python 里什么东西是用链表实现的？ collections.deque 底层是一串定长块组成的双向链表，所以它的两端增删都是 O(1)。
