第 2 课 · 链表

链表的每个节点只记两样东西：自己的值和下一个是谁。像寻宝游戏，每张纸条告诉你下一张在哪。

实战里怎么写：用 deque 和 OrderedDict

业务代码里几乎没人手写链表节点。真正要用到链表“两端增删快、已知位置挪动快”的特性时，直接用标准库：

场景用什么代价
两端都要增删（任务队列、工单、BFS）collections.deque 的 append / appendleft / popleft两端 O(1)；list.pop(0) 是 O(n)
只留最近 N 条deque(maxlen=N)O(1)，满了自动挤掉另一头
找到某项后挪到最前 / 最后（最近打开、LRU）collections.OrderedDict 的 move_to_endO(1)，底层是哈希表 + 双向链表
按值删中间某一项deque.remove(value)O(n)，要先找到它
from collections import deque

tickets = deque(["退款-101", "咨询-102"])
tickets.append("投诉-103")          # 普通工单排队尾，O(1)
tickets.appendleft("加急-999")      # 加急插队头，O(1)
next_ticket = tickets.popleft()     # 客服从队头取，O(1)
tickets.remove("咨询-102")          # 用户撤回：O(n)，找不到抛 ValueError

完整可运行的版本在 examples/linked_list_in_practice.py（uv run examples/linked_list_in_practice.py），还有一个用 OrderedDict 做的“最近打开的文件”。下面看链表为什么能把这些操作做到 O(1)。

长什么样

head → 1→2→3→ None（tail 指向 3） 
class Node:
    def __init__(self, value, next=None):
        self.value = value
        self.next = next

节点不用排在一起，散落在内存的任何地方都行，靠 next 串起来。

和数组比一比

操作数组链表
按下标取第 i 个O(1)O(n)，只能从头一个个数
头部插入 / 删除O(n)O(1)
尾部插入均摊 O(1)O(1)（前提是记着 tail）

一句话：数组擅长随机访问，链表擅长在已知位置增删。

头部插入：两步，顺序不能反

0→1→2→None 
def appendleft(self, value):
    new_node = Node(value, self.head)   # ① 新节点先指向旧的头
    self.head = new_node                # ② 再把 head 挪到新节点
    if self.tail is None:               # 原来是空链表：新节点既是头也是尾
        self.tail = new_node
    self._size += 1

如果先挪 head，旧的头就找不到了。改指针之前，先想清楚谁会因此“失联”。

删除：要找的是“前一个”

单链表只能往后走。要删掉 2，得站在 1 上，让 1 跳过 2：

1⤼23 prev.next = prev.next.next

小技巧：哨兵节点。在 head 前面放一个假节点 dummy，这样删头节点和删中间节点就是同一种写法，不用单独判断。

反转：三个指针一起往前走

def reverse(self):
    previous_node, current_node = None, self.head
    while current_node is not None:
        next_node = current_node.next      # 先记住后面
        current_node.next = previous_node  # 掉头
        previous_node = current_node       # 两个指针一起前进
        current_node = next_node
    self.head, self.tail = self.tail, self.head

别忘了最后一行：反转之后 head 和 tail 要互换。

动手玩

建议依次试试：reverse（用“上一步 / 下一步”慢慢看三个指针怎么走）；把值设成 4 再点 remove，看删掉尾巴时 tail 怎么退回；连点 pop_front 直到链表变空。

最容易错的三个地方

  • 链表变空的时候，head 和 tail 都要变回 None。
  • 删掉的正好是尾巴，tail 要退回到前一个节点。
  • 只有一个节点时，head 和 tail 是同一个节点。

测试会专门检查这三种情况。

练习

补全 dsa/linked_list.py 里的 LinkedList。方法名和 deque 一样，写完就能直接替换着用：append、appendleft、popleft、remove、reverse，再加上 len()、for、in。动画里的 push_front / push_back / pop_front 分别对应 appendleft / append / popleft。异常和标准库一致：空链表 popleft 抛 IndexError，remove 找不到抛 ValueError。

建议顺序：appendleft → __iter__（用 yield）→ append → popleft → __contains__ → remove → reverse。

uv run dsa/linked_list.py               # 客服工单队列的端到端例子，逐条打印期望和实际
uv run pytest tests/test_linked_list.py

自测

1. 为什么链表取第 i 个是 O(n)？ 节点不连续，没法算地址，只能从 head 开始沿着 next 走 i 步。
2. 有 tail 指针，为什么删尾巴（deque 的 pop）在单链表上还是 O(n)？ 删掉尾巴以后，tail 要指向倒数第二个节点，可单链表没法往回走，只能从头找。双向链表就能做到 O(1)。
3. Python 里什么东西是用链表实现的？ collections.deque 底层是一串定长块组成的双向链表，所以它的两端增删都是 O(1)。
