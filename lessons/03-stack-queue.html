第 3 课 · 栈与队列

栈是后进先出（LIFO），像一摞盘子，只能动最上面那个；队列是先进先出（FIFO），像排队买票，从队尾进、从队头出。

实战里怎么写：list 当栈，deque 当队列

业务代码里没人专门写 Stack / Queue 类，直接用现成的：

场景用什么代价
栈（撤销、括号匹配、深度优先）list 的 append / pop / [-1]均摊 O(1)
单线程里的队列（任务排队、BFS）collections.deque 的 append / popleftO(1)；list.pop(0) 是 O(n)
多线程之间传任务标准库 queue.Queue 的 put / getO(1)，自带锁，get 可以阻塞等待
from collections import deque

def brackets_balanced(text):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for character in text:
        if character in "([{":
            stack.append(character)                  # 压栈
        elif character in pairs:
            if not stack or stack.pop() != pairs[character]:
                return False
    return not stack                                 # 最后栈要空

只在 list 的末尾进出，第 1 课讲过，这都是 O(1)。函数调用、撤销、括号匹配，用的都是栈。

队列：为什么不能也用 list

队列要从头部取。list.pop(0) 会让后面所有元素往左挪一格，是 O(n)。

办法：元素不挪，只挪下标。用 head 记住队头在哪，出队时 head += 1 就行。可这样前面空出来的格子就浪费了。

环形队列：走到末尾就绕回 0

把数组首尾接起来，看成一个环。只记两个数：head（队头下标）和 size（有几个）。

def append(self, value):
    ...                                            # 满了先扩容，见下一节
    tail = (self._head + self._size) % self.capacity   # 下一个元素放哪
    self._data[tail] = value
    self._size += 1

def popleft(self):
    if self._size == 0:
        raise IndexError("popleft from empty queue")
    value = self._data[self._head]
    self._head = (self._head + 1) % self.capacity      # 出队后队头往前走
    self._size -= 1
    return value

% capacity 就是“回绕”：下标走到 4 时变回 0。

满了怎么办：翻倍扩容

和动态数组一样，开一个两倍长的新数组。但搬家时要按队列顺序搬：从 head 开始数，第 k 个元素在旧数组的 (head + k) % capacity，放进新数组的第 k 格。搬完 head 归 0。

直接按下标 0、1、2… 复制是错的：上图里 5 会跑到 3、4 前面，顺序就乱了。

操作栈（list）环形队列

动手玩

栈：连点几次 push，再连点 pop，看谁先出来。

环形队列：一开始 1、2 已经出队了，head 在 2。点一次 enqueue，看 tail 怎么从 3 绕回 0；再点两次，看满了以后怎么按队列顺序搬家。

最容易错的三个地方

  • 队尾下标忘了 % capacity，越界。
  • “空”和“满”时 head 都等于 tail，光看下标分不出来，所以要单独记 size。
  • 扩容时按旧下标顺序复制，队列顺序乱掉。

自测

1. 用两个栈能不能实现一个队列？ 能。进队压进栈 A；出队时如果栈 B 空，就把 A 全部倒进 B（顺序正好反过来），再从 B 弹。每个元素最多被倒一次，均摊 O(1)。
2. 不记 size，只记 head 和 tail，怎么区分空和满？ 常见做法是故意空一格：(tail + 1) % capacity == head 算满。代价是永远浪费一个格子。
3. Python 里实际该用什么当队列？ 单线程用 collections.deque，两端进出都是 O(1)，BFS（第 13 课）就靠它；多线程之间传任务用 queue.Queue。
