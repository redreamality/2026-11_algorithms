第 3 课 · 栈与队列

栈是后进先出（LIFO），像一摞盘子，只能动最上面那个；队列是先进先出（FIFO），像排队买票，从队尾进、从队头出。

先理解核心对象模板与不变量应用场景练习与自测

开始前要会：Python —— 魔法方法（__len__、__iter__、__bool__ 的退路）、生成器、@property、异常约定（IndexError）、% 取余、嵌套函数、海象运算符 :=；前面的课 —— 第 1 课 · 动态数组（翻倍扩容、均摊 O(1)）、第 2 课 · 链表（append / popleft 这套方法名）。

先理解：两种取出顺序

问题先看“谁应该先出来”：后进先出就是栈，先进先出就是队列。这个顺序决定了入口、出口和底层结构。

应用场景：list 当栈，deque 当队列

业务代码里没人专门写 Stack / Queue 类，直接用现成的：

场景用什么代价
栈（撤销、括号匹配）list 的 append / pop / [-1]均摊 O(1)
单线程里的队列（任务排队）collections.deque 的 append / popleftO(1)；list.pop(0) 是 O(n)

from collections import deque

def brackets_balanced(text):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for character in text:
        if character in "([{":
            stack.append(character)                  # 压栈
        elif character in pairs:
            if not stack or stack.pop() != pairs[character]:
                return False
    return not stack                                 # 最后栈要空

pending = deque(["下载 a.zip", "发邮件"])
while pending:
    job = pending.popleft()                          # 先来先处理，O(1)
    ...

collections.deque（读作 “deck”，double-ended queue，双端队列）是这一课第一次正式出场的标准库工具。用法和 list 很像，只是多了一组操作左端的方法：

from collections import deque

line = deque(["a", "b"])        # 用任何可迭代对象建，空的就是 deque()
line.append("c")                # 右端进：deque(['a', 'b', 'c'])
line.appendleft("z")            # 左端进：deque(['z', 'a', 'b', 'c'])
line.popleft()                  # 'z'   左端出；空的时候抛 IndexError
line.pop()                      # 'c'   右端出
line[0], len(line), "a" in line # ('a', 2, True)   下标、len、in 都能用（但按下标取中间元素是 O(n)）

recent = deque(maxlen=3)        # 限长：满了以后从一端进，另一端自动挤掉一个
for page in ["首页", "搜索", "商品", "购物车"]:
    recent.append(page)
print(recent)                   # deque(['搜索', '商品', '购物车'], maxlen=3)

第 1 课里“只留最近 3 条”要手动 del items[0]（O(n)），换成 deque(maxlen=3) 就是 O(1)。CPython 的 deque 底层是一串定长小块串成的双向链表（第 2 课链表的升级版）；下面讲另一种做到两头都快的办法：环形队列。

核心对象：栈、队列与环形下标

栈：一个 list 就够了

栈底123← 栈顶（list 末尾） 
items.append(x)   # push：O(1)
items.pop()       # pop：O(1)
items[-1]         # peek：O(1)

只在 list 的末尾进出，第 1 课讲过，这都是 O(1)。撤销、括号匹配用的都是栈；Python 执行函数调用时也靠一个栈记住“回到哪里”，第 5 课讲递归时会看到。

模板与不变量：head、size 与回绕

队列：为什么不能也用 list

队列要从头部取。list.pop(0) 会让后面所有元素往左挪一格，是 O(n)。

办法：元素不挪，只挪下标。用 head 记住队头在哪，出队时 head += 1 就行。可这样前面空出来的格子就浪费了。

环形队列：走到末尾就绕回 0

把数组首尾接起来，看成一个环。只记两个数：head（队头下标）和 size（有几个）。

下标0123
格子5·34 head = 2，size = 3，队列顺序是 3、4、5 
def append(self, value):
    ...                                            # 满了先扩容，见下一节
    tail = (self._head + self._size) % self.capacity   # 下一个元素放哪
    self._data[tail] = value
    self._size += 1

def popleft(self):
    if self._size == 0:
        raise IndexError("popleft from empty queue")
    value = self._data[self._head]
    self._head = (self._head + 1) % self.capacity      # 出队后队头往前走
    self._size -= 1
    return value

% capacity 就是“回绕”：下标走到 4 时变回 0。

满了怎么办：翻倍扩容

和动态数组一样，开一个两倍长的新数组。但搬家时要按队列顺序搬：从 head 开始数，第 k 个元素在旧数组的 (head + k) % capacity，放进新数组的第 k 格。搬完 head 归 0。

直接按下标 0、1、2… 复制是错的：上图里 5 会跑到 3、4 前面，顺序就乱了。

复杂度

操作栈（list）环形队列
放进去均摊 O(1)均摊 O(1)（偶尔扩容 O(n)）
取出来O(1)O(1)
看一眼（peek）O(1)O(1)

动手玩

栈：连点几次 push，再连点 pop，看谁先出来。

环形队列：一开始 1、2 已经出队了，head 在 2。点一次 enqueue，看 tail 怎么从 3 绕回 0；再点两次，看满了以后怎么按队列顺序搬家。

最容易错的三个地方

  • 队尾下标忘了 % capacity，越界。
  • “空”和“满”时 head 都等于 tail，光看下标分不出来，所以要单独记 size。
  • 扩容时按旧下标顺序复制，队列顺序乱掉。

自测

1. 用两个栈能不能实现一个队列？ 能。进队压进栈 A；出队时如果栈 B 空，就把 A 全部倒进 B（顺序正好反过来），再从 B 弹。每个元素最多被倒一次，均摊 O(1)。
2. 不记 size，只记 head 和 tail，怎么区分空和满？ 常见做法是故意空一格：(tail + 1) % capacity == head 算满。代价是永远浪费一个格子。
3. Python 里实际该用什么当队列？ 单线程用 collections.deque，两端进出都是 O(1)，后面第 13 课的广度优先搜索就靠它；多线程之间传任务用 queue.Queue。
