1. 运行方式：uv run、if __name__ == "__main__"、assert

本项目用 uv 管理 Python 和依赖。uv run 文件.py 会自动用项目的虚拟环境去跑，不用自己激活。

每个骨架文件末尾都有这样一段：

def double(x):
    return x * 2


if __name__ == "__main__":
    # 只有直接运行这个文件时（uv run 文件.py）才会执行；
    # 被别的文件 import 时（比如 pytest 导入它做测试）不会执行。
    assert double(3) == 6, "double(3) 应该是 6"
    print("全部通过")
  • __name__ 是 Python 自动给每个文件设的变量：直接运行时它等于 "__main__"，被 import 时等于模块名。
  • assert 条件, 说明：条件为假就抛 AssertionError，并带上说明。examples/ 里的实战脚本就是靠一串 assert 检查自己算得对不对。

2. f-string：{x!r}、{x:.2f}、{x=}

字符串前加 f，花括号里可以直接写表达式。冒号后面是格式，!r 表示用 repr() 显示（字符串会带引号，方便看出空格和类型）。

name = "Bob"
price = 3.14159
items = [1, 2]

print(f"你好，{name}")          # 你好，Bob
print(f"{name!r}")              # 'Bob'      带引号，一眼看出是字符串
print(f"{price:.2f}")           # 3.14       保留两位小数
print(f"{12345:,}")             # 12,345     千分位
print(f"{len(items) = }")       # len(items) = 2   调试用：连表达式一起打印
print(f"[{name:>6}]")           # [   Bob]  右对齐，占 6 格

类里的 __repr__ 常写成 f"LinkedList({list(self)!r})"，就是这个用法。

3. 推导式与生成器表达式

一行生成一个新容器，读法是“对 … 里的每个 …，如果 …，就放进来 …”：

nums = [3, -1, 4, -1, 5]

squares = [n * n for n in nums]                 # 列表：[9, 1, 16, 1, 25]
positives = [n for n in nums if n > 0]          # 带条件：[3, 4, 5]
unique = {n for n in nums}                      # 集合：{3, -1, 4, 5}
index_of = {n: i for i, n in enumerate(nums)}   # 字典：值 → 最后一次出现的下标（enumerate 见第 5 节）
grid = [[0] * 3 for _ in range(2)]              # 2 行 3 列的二维表：[[0, 0, 0], [0, 0, 0]]

二维表一定要用推导式建。[[0] * 3] * 2 看着一样，其实两行是同一个 list，改一行另一行跟着变。同样道理，grid.copy() 和 grid[:] 只复制外层，里面的每一行还是共用的；要连里层一起复制，用 [row[:] for row in grid] 或 copy.deepcopy(grid)。

把方括号换成圆括号，就是生成器表达式：不先造出整个 list，而是边算边给。直接传给 sum、any、max 这类函数时，连圆括号都可以省：

total = sum(n * n for n in nums)              # 不建中间 list，省内存
has_negative = any(n < 0 for n in nums)       # 碰到第一个负数就停，不再往后算
longest = max(len(word) for word in ["a", "abc", "ab"])   # 3

生成器是怎么做到“边算边给”的，见第 13 节。

4. 解包：多重赋值、交换、*rest、*args

x, y = 1, 2
x, y = y, x                 # 交换，不需要临时变量：x = 2, y = 1

point = (3, 4)
row, col = point            # 元组拆开赋给两个变量

first, *rest = [1, 2, 3, 4]       # first = 1, rest = [2, 3, 4]
*init, last = [1, 2, 3, 4]        # init = [1, 2, 3], last = 4

for name, score in [("Ann", 90), ("Bob", 85)]:   # for 里也能拆
    print(name, score)

merged = [*[1, 2], *[3, 4]]       # 把两个 list 摊开拼起来：[1, 2, 3, 4]
print(*[1, 2, 3])                 # 等于 print(1, 2, 3)


def total(*numbers):              # 收任意多个位置参数，numbers 是一个元组
    return sum(numbers)


total(1, 2, 3)                    # 6

注意 x, y = y, x 的执行顺序：右边先整体算出一个元组 (2, 1)，再依次赋给左边。链表反转里会写 previous_node, current_node = current_node, current_node.next，靠的就是这一点。

5. 循环小工具：enumerate、zip、range 倒序、切片步长、divmod

words = ["a", "b", "c"]

for index, word in enumerate(words):        # 同时拿到下标和值：0 a、1 b、2 c
    ...
for index, word in enumerate(words, 1):     # 下标从 1 开始数

names = ["Ann", "Bob"]
scores = [90, 85]
for name, score in zip(names, scores):      # 两个序列并排走，按短的那个停
    ...
dict(zip(names, scores))                    # {'Ann': 90, 'Bob': 85}

for i in range(5, 0, -1):                   # 倒着数：5 4 3 2 1（终点 0 不含）
    ...

nums = [0, 1, 2, 3, 4, 5]
nums[::-1]        # [5, 4, 3, 2, 1, 0]  新建一个倒序副本
nums[::2]         # [0, 2, 4]           每隔一个取一个
nums[1:4]         # [1, 2, 3]           左闭右开
nums[-1]          # 5                   负数下标从末尾数

quotient, remainder = divmod(17, 5)         # (3, 2)，等于 (17 // 5, 17 % 5)

切片总是新建一个 list，要把切出来的元素一个个复制过去，并不是“免费”的。在循环里反复切片会悄悄变慢，第 0 课讲完复杂度后再细说。

6. 函数当参数：lambda 与 key=

Python 里函数也是一个值，可以存进变量、当参数传。lambda 参数: 表达式 是一个没有名字的小函数，只能写一个表达式，表达式的值就是返回值：

def by_length(word):
    return len(word)

by_length_lambda = lambda word: len(word)     # 和上面的 def 等价

最常见的用途是给 sorted、min、max 传 key=：先对每个元素算出 key，再按 key 比较，返回的仍然是原来的元素。

students = [("Ann", 90), ("Bob", 85), ("Cid", 90)]

sorted(students, key=lambda student: student[1])
# [('Bob', 85), ('Ann', 90), ('Cid', 90)]   按分数升序

sorted(students, key=lambda student: (-student[1], student[0]))
# [('Ann', 90), ('Cid', 90), ('Bob', 85)]   分数降序；同分按名字升序

max(students, key=lambda student: student[1])   # ('Ann', 90)  同样大时取第一个
sorted(["b", "A", "c"], key=str.lower)          # ['A', 'b', 'c']  直接传现成的函数也行
  • key 返回元组时按位比较：先比第一项，相等再比第二项。数字取负号就能让这一项倒过来排。
  • sorted(x) 返回新 list，不动原数据；x.sort() 原地排、返回 None。
  • Python 的排序是稳定的：key 相同的元素，排完后保持原来的先后顺序。为什么重要，第 7 课讲。
  • operator.itemgetter(1) 等价于 lambda item: item[1]，在别人的代码里会见到。
  • sorted(x, reverse=True) 整体倒过来排（降序），稳定性不变。
  • max(x, default=0)：x 为空时返回 0，而不是抛 ValueError。min 同理。

循环里造 lambda 的坑：lambda 记住的是变量，不是当时的值。循环结束后再调用，它们看到的都是变量最后的值：

adders = [lambda x: x + step for step in range(3)]
[add(10) for add in adders]          # [12, 12, 12]，不是 [10, 11, 12]

adders = [lambda x, step=step: x + step for step in range(3)]   # 用默认参数把当时的值“钉住”
[add(10) for add in adders]          # [10, 11, 12]

骨架文件里的自测函数 show(title, compute, expected) 也是这个思路：compute 传一个 lambda: len(tickets) 进去，show 在 try 里调用它，这样没实现的方法抛异常也不会让整个脚本停下。

7. 字典小工具：get、setdefault、defaultdict、Counter

这一节只讲怎么用。dict 内部为什么查找这么快，是第 4 课的内容。

stock = {"apple": 3}

stock.get("pear")          # None       键不存在不报错（stock["pear"] 会抛 KeyError）
stock.get("pear", 0)       # 0          可以给默认值
dict.fromkeys(["a", "b"])  # {'a': None, 'b': None}
list(dict.fromkeys([3, 1, 3, 2]))   # [3, 1, 2]   去重并保留顺序（dict 记得插入顺序）

按某个东西分组是最常见的需求，有三种写法，效果一样：

words = ["apple", "avocado", "banana"]

# 写法一：手动判断
groups = {}
for word in words:
    if word[0] not in groups:
        groups[word[0]] = []
    groups[word[0]].append(word)

# 写法二：setdefault(键, 默认值)：键不在就先放进默认值；不管在不在，都返回字典里这个键对应的值
groups = {}
for word in words:
    groups.setdefault(word[0], []).append(word)

# 写法三：defaultdict(list)：访问不存在的键时，自动调用 list() 造一个空列表放进去
from collections import defaultdict

groups = defaultdict(list)
for word in words:
    groups[word[0]].append(word)

# 三种都得到 {'a': ['apple', 'avocado'], 'b': ['banana']}

defaultdict 的坑：只是读一下 groups["z"]，也会往里面插入一个 "z": []。只想查不想插，就用 "z" in groups 或 groups.get("z")。

计数用 Counter，它是一个“值默认为 0 的 dict”：

from collections import Counter

counts = Counter("banana")       # Counter({'a': 3, 'n': 2, 'b': 1})
counts["a"]                      # 3
counts["z"]                      # 0   不存在的键返回 0，而且不会插入
counts.most_common(2)            # [('a', 3), ('n', 2)]
counts["b"] += 1                 # 当普通 dict 用，可以直接加

8. 异常：try/except/else、raise ... from、with

def parse_age(text):
    try:
        age = int(text)
    except ValueError as error:          # 只接住会出现的那一种异常
        raise ValueError(f"年龄必须是整数：{text!r}") from error
    else:                                # try 里没出错才走这里
        if age < 0:
            raise ValueError(f"年龄不能是负数：{age}")
        return age


try:
    parse_age("abc")
except ValueError as error:
    print(error)                         # 年龄必须是整数：'abc'
  • raise 新异常 from 原异常：换成对调用者更好懂的说法，同时把原始原因也挂在报错信息里，排查时两层都能看到。
  • 不要写光秃秃的 except:，它会把拼错变量名之类的 bug 也吞掉。
  • 自定义异常：class EmptyError(Exception): pass，或者继承一个意思相近的内置异常，例如 class QueueEmpty(IndexError): pass，这样调用者 except IndexError 也能接住它。

我们手写的数据结构，抛的异常要和标准库一致，别人才能无缝替换：

情况标准库的做法例子
按位置取，越界或者容器为空IndexError[].pop()、[1][5]
按键取，键不存在KeyError(key){}["x"]
值本身不对（找不到、格式错）ValueError[1].remove(2)、int("abc")
类型不对TypeError1 + "a"

with 用来管理“用完必须收尾”的资源，比如文件。离开 with 块时会自动关闭，中途抛异常也会关：

with open("orders.csv", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
# 到这里文件已经关闭了

测试里的 with pytest.raises(IndexError): 也是 with：块里的代码必须抛出 IndexError，测试才算通过。

9. 类型标注：list[int]、Node | None、Iterator

骨架里函数签名上的类型标注只是注释，Python 运行时不检查。它的作用是告诉读代码的人：参数应该传什么，会返回什么。

from collections.abc import Callable, Iterable, Iterator


def average(scores: list[float]) -> float: ...           # 参数是 float 的 list，返回 float
def find(names: dict[str, int], name: str) -> int | None: ...   # 可能返回 int，也可能返回 None
def total(items: Iterable[int]) -> int: ...              # 任何能 for 的东西：list、set、生成器……
def walk() -> Iterator[int]: ...                        # 生成器函数（第 13 节）一般这样标
def apply(func: Callable[[int], int], x: int) -> int: ...   # func 是“收一个 int、返回 int”的函数
  • A | B 读作“A 或者 B”。Node | None 是最常见的：链表和树里，“下一个节点”可能不存在。
  • 类型写在引号里（next: "Node | None"），是因为 Node 这个类还没定义完，就在自己的 __init__ 里引用了自己。加引号可以推迟求值。
  • Iterable 只承诺“能 for”；Iterator 还承诺“能 next()”。区别见第 13 节。
  • tuple[int, str] 是“正好两项、分别是 int 和 str”的元组；tuple[str, ...] 是“任意多项、每项都是 str”的元组。

10. 类：@property、@classmethod、@dataclass、NamedTuple

class Account:
    def __init__(self, owner, balance=0):    # 创建对象时自动调用
        self.owner = owner                    # self 就是“这个对象自己”
        self._balance = balance               # 下划线开头：约定为内部用，外面别直接改

    @property
    def balance(self):                        # 像属性一样读：account.balance（不加括号）
        return self._balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("金额必须为正")
        self._balance += amount

    @classmethod
    def from_text(cls, text):                 # 另一种创建方式：Account.from_text("Ann:100")
        owner, balance = text.split(":")      # cls 就是 Account 这个类本身
        return cls(owner, int(balance))

    @staticmethod
    def is_valid_owner(name):                 # 和对象、类都无关，只是放在类里的普通函数
        return name.isalpha()


account = Account.from_text("Ann:100")
account.deposit(50)
print(account.balance)                        # 150
account.balance = 0                           # AttributeError：property 只读

只是装数据的类，不用手写 __init__，用 @dataclass 自动生成 __init__、__repr__、__eq__：

from dataclasses import dataclass, field


@dataclass
class Order:
    order_id: int
    amount: float
    tags: list[str] = field(default_factory=list)   # 可变的默认值必须这样写


order = Order(1, 9.9)
print(order)                      # Order(order_id=1, amount=9.9, tags=[])
order == Order(1, 9.9)            # True，按字段比较


@dataclass(order=True)            # order=True：还能按字段顺序比大小，可以直接排序
class Task:
    priority: int
    name: str


sorted([Task(2, "b"), Task(1, "z")])   # [Task(priority=1, name='z'), Task(priority=2, name='b')]

为什么默认值要写 field(default_factory=list)：如果写 tags: list = []，所有对象会共用同一个 list。普通函数的默认参数也有同样的坑，所以骨架里写 def __init__(self, items=())，用不可变的空元组当默认值。

不可变的小记录可以用 NamedTuple：它就是一个元组，但每一项有名字。

from typing import NamedTuple


class Edge(NamedTuple):
    start: str
    end: str
    weight: int


edge = Edge("A", "B", 5)
edge.weight          # 5      按名字取
edge[2]              # 5      也能按下标取
start, end, weight = edge     # 也能解包
edge.weight = 6      # AttributeError：不能改

isinstance(x, (int, float)) 判断 x 是不是其中某个类型（或它们的子类）的对象。

11. 魔法方法：让自己的类支持 len、in、for、[]、==、<

前后各两个下划线的方法叫“魔法方法”（dunder）。你不直接调用它们，而是 Python 在遇到对应写法时替你调用：

你写Python 实际调用
len(x)x.__len__()
item in xx.__contains__(item)
for item in xx.__iter__()，见第 13 节
x[i] / x[i] = v / del x[i]__getitem__ / __setitem__ / __delitem__
x == yx.__eq__(y)
x < yx.__lt__(y)
if x:x.__bool__()；没有就看 len(x) != 0
在交互环境或 print 列表里显示 xx.__repr__()
class Playlist:
    def __init__(self, songs=()):
        self._songs = list(songs)

    def __len__(self):
        return len(self._songs)

    def __getitem__(self, index):
        return self._songs[index]          # 越界时 list 自己会抛 IndexError

    def __contains__(self, song):
        return song in self._songs

    def __eq__(self, other):
        if not isinstance(other, Playlist):
            return NotImplemented          # 不认识对方的类型：交给 Python 去试对方的 __eq__
        return self._songs == other._songs

    def __repr__(self):
        return f"Playlist({self._songs!r})"


playlist = Playlist(["a", "b"])
len(playlist), playlist[0], "b" in playlist     # (2, 'a', True)
bool(Playlist())                                # False，因为长度是 0

NotImplemented（不是 NotImplementedError）是一个特殊值，意思是“这次比较我不管”，Python 会接着试对方的 __eq__，都不管就按“不相等”处理。而 raise NotImplementedError 是骨架里“这里还没写”的占位。两者名字像，用途完全不同。

只要定义了 __lt__，sorted、min、max 就能直接比较你的对象。

12. 继承 collections.abc：写几个方法，白送一堆

collections.abc 里是一些“容器模板”。继承它，写好它要求的几个基础方法，其余方法它都替你写好了：

继承你必须写白送的
Sequence（只读序列）__getitem__、__len__in、for、reversed、index、count
MutableSequence（可改序列，像 list）上面两个 + __setitem__、__delitem__、insert再加 append、pop、remove、extend、+= 等
Mapping（只读字典）__getitem__、__iter__、__len__in、get、keys、values、items、==
MutableMapping（可改字典，像 dict）上面三个 + __setitem__、__delitem__再加 pop、setdefault、update 等
from collections.abc import Sequence


class Playlist(Sequence):
    def __init__(self, songs=()):
        self._songs = list(songs)

    def __getitem__(self, index):
        return self._songs[index]

    def __len__(self):
        return len(self._songs)


playlist = Playlist(["a", "b", "a"])
"b" in playlist                 # True   白送的
list(reversed(playlist))        # ['a', 'b', 'a']
playlist.count("a")             # 2
playlist.index("b")             # 1

白送的方法是用你写的基础方法拼出来的，比如 in 就是从头 for 一遍。它们对，但不一定最快。需要更快时，自己重写那一个方法就行（比如 __contains__）。

注意：Mapping 的 get 和 in 是靠“__getitem__ 抛 KeyError”来判断键不存在的。所以手写字典类时，找不到键必须抛 KeyError，抛别的异常或返回 None 都会出错。

13. 生成器：yield、next()、iter()

函数里只要出现 yield，它就变成生成器函数。调用它不会马上执行函数体，而是返回一个生成器对象。每次向它要下一个值（next()），函数体就从上次停下的地方往下跑，跑到下一个 yield 交出一个值，然后暂停，局部变量原样保留。函数体跑完时，生成器结束。

def count_down(n):
    while n > 0:
        yield n          # 交出 n，然后停在这里
        n -= 1           # 下次 next() 从这一行接着跑


numbers = count_down(3)  # 只是造了一个生成器，函数体一行都没跑
next(numbers)            # 3
next(numbers)            # 2
next(numbers)            # 1
next(numbers)            # 抛 StopIteration：没有更多值了

for n in count_down(3):  # for 帮你反复 next()，碰到 StopIteration 就正常结束
    print(n)             # 3 2 1

动手：一步步执行 count_down(3)，看函数在哪里暂停、局部变量 n 怎么保留下来。

for 循环背后的规矩（迭代协议）是：

  1. for x in obj 先调用 iter(obj)，也就是 obj.__iter__()，拿到一个迭代器。
  2. 然后反复调用 next(迭代器)，直到它抛出 StopIteration。

所以，让自己的类能被 for，最省事的办法是把 __iter__ 写成生成器：

class Node:
    def __init__(self, value, next=None):
        self.value = value
        self.next = next


class LinkedList:
    def __init__(self, head=None):
        self.head = head

    def __iter__(self):
        node = self.head
        while node is not None:
            yield node.value
            node = node.next


chain = LinkedList(Node(1, Node(2, Node(3))))
list(chain)       # [1, 2, 3]
2 in chain        # True：没写 __contains__ 时，in 会用 __iter__ 挨个找

生成器的特点和坑：

  • 省内存：一次只产出一个值，不需要先造出整个 list。
  • 懒：不往下要，就不往下算。所以可以在中途停下：any(...) 找到一个就停。
  • 只能走一遍：走完就空了。numbers = count_down(3) 之后 list(numbers) 是 [3, 2, 1]，再 list(numbers) 就是 []。需要多次遍历时，先 list() 存下来。
  • next(iterator, 默认值)：没有下一个值时返回默认值，不抛异常。常用来取“第一个满足条件的”：next((n for n in nums if n > 3), None)。
  • 遍历的时候别改容器：在 for 一个 dict 或 set 的过程中往里加、删元素，会抛 RuntimeError；list 不报错，但会跳过元素。要改就先 list() 拷一份再遍历。

14. 委托：yield from

yield from 可迭代对象 等于“把它里面的值一个个 yield 出去”：

def chain_all(*iterables):
    for iterable in iterables:
        yield from iterable          # 等价于：for item in iterable: yield item


list(chain_all([1, 2], "ab", range(3)))   # [1, 2, 'a', 'b', 0, 1, 2]

它最大的用处是在一个生成器里调用另一个生成器：外层把“产出值”这件事整个委托给里层，里层产出的每个值都原样穿过外层，交到最外面的 for 手里。

def numbers_then_letters():
    yield from count_down(2)         # 先把 count_down(2) 的 2、1 交出去
    yield from "ab"                  # 再交出 'a'、'b'
    yield "done"


list(numbers_then_letters())          # [2, 1, 'a', 'b', 'done']

动手：看外层生成器怎么把 next() 转交给里层、里层产出的值怎么穿过外层。

常见错误：在生成器里调用另一个生成器却忘了写 yield from。只写 count_down(2) 一行，只是造了一个生成器对象然后扔掉，什么都不会产出。第 5 课以后，“函数调用自己”（递归）的生成器会经常用到 yield from，比如按顺序遍历一棵树。

15. 嵌套函数：闭包、nonlocal、global

函数里可以再定义函数。里层函数能读外层函数的变量（这叫闭包）。后面很多课会这样写：外层函数准备好数据，里层定义一个辅助函数干活，最后调用它。

def count_long_words(words, min_length):
    def is_long(word):
        return len(word) >= min_length      # 直接读外层的 min_length
    return sum(1 for word in words if is_long(word))

但如果里层要给外层变量重新赋值，必须先声明 nonlocal。不声明的话，Python 会把它当成里层自己的新局部变量：

def make_counter():
    count = 0

    def increment():
        nonlocal count          # 不写这行，下一行会报 UnboundLocalError
        count += 1
        return count

    return increment


counter = make_counter()
counter(), counter()            # (1, 2)：count 被保存在闭包里
  • 只是修改外层变量指向的对象（比如 result.append(x)、seen.add(x)），不算重新赋值，不需要 nonlocal。
  • global 变量名 是同样的意思，只不过针对的是文件顶层的变量。尽量少用：全局状态让函数的结果依赖外部，难测试。

16. 装饰器与 functools.cache

写在函数定义上一行的 @某某 叫装饰器。@decorator 加在 def f 上，等价于定义完以后执行 f = decorator(f)：把原函数交给装饰器，换成一个加了额外功能的新函数。前面见过的 @property、@classmethod、@dataclass 都是装饰器。

functools.cache 给函数加上“记住结果”的功能：同样的参数第二次调用时，直接返回上次的结果，不再执行函数体。

from functools import cache


@cache
def slow_square(n):
    print(f"真的在算 {n}")
    return n * n


slow_square(4)     # 打印“真的在算 4”，返回 16
slow_square(4)     # 什么都不打印，直接返回 16
slow_square.cache_clear()   # 清空记住的结果
  • 它用一个 dict 记结果，键就是参数。所以参数必须能当 dict 的键：数字、字符串、元组可以，list、dict、set 不行（会抛 TypeError: unhashable type）。为什么，第 4 课讲。
  • functools.lru_cache(maxsize=128) 是有容量上限的版本：满了就扔掉最久没用的结果。“最久没用”具体怎么实现，第 30 课讲。
  • 它在算法里的大用处是“记忆化”，第 19 课专门讲。

自己写一个装饰器：收一个函数，返回一个包了一层的新函数。functools.wraps 把原函数的名字和文档复制到新函数上，否则调试时看到的名字全是 wrapper：

from functools import wraps


def count_calls(func):
    @wraps(func)
    def wrapper(*args, **kwargs):        # 原样收下任何参数（见第 21 节）
        wrapper.calls += 1
        return func(*args, **kwargs)     # 原样转交给原函数
    wrapper.calls = 0
    return wrapper


@count_calls
def add(a, b):
    return a + b


add(1, 2), add(3, 4)
add.calls          # 2
add.__name__       # 'add'（没有 @wraps 的话是 'wrapper'）

17. itertools：accumulate、pairwise、combinations 等

标准库 itertools 里都是返回迭代器的小工具，要看结果时用 list() 包一下：

from itertools import accumulate, chain, combinations, islice, pairwise, permutations, product

list(accumulate([1, 2, 3, 4]))          # [1, 3, 6, 10]        逐个累加
list(accumulate([3, 1, 4], max))        # [3, 3, 4]            逐个取“到目前为止最大”
list(pairwise([1, 2, 3]))               # [(1, 2), (2, 3)]     相邻两个一组
list(chain([1, 2], [3]))                # [1, 2, 3]            首尾接起来
list(islice(count_down(100), 3))        # [100, 99, 98]        只取前 3 个，生成器也能用
list(combinations("abc", 2))            # [('a','b'), ('a','c'), ('b','c')]   不管顺序的组合
list(permutations("ab"))                # [('a','b'), ('b','a')]              排列，顺序不同算不同
list(product([0, 1], repeat=2))         # [(0,0), (0,1), (1,0), (1,1)]        笛卡尔积，相当于两层 for
list(accumulate([1, 2, 3], initial=0))  # [0, 1, 3, 6]         前面多放一个起始值（前缀和常用）
list(chain.from_iterable([[1], [2, 3]]))  # [1, 2, 3]          把“一串列表”摊平一层

from itertools import count, takewhile

ids = count(1)                           # 无穷的 1, 2, 3, ……；常用来发递增编号
next(ids), next(ids)                     # (1, 2)
list(takewhile(lambda n: n < 4, [1, 3, 5, 2]))   # [1, 3]  从头取，碰到第一个不满足的就停

（count_down 是第 13 节定义的生成器。）

复杂度：O(n) 读作“大 O n”，意思是输入有 n 个元素时，耗时大致跟 n 成正比（严格定义见第 00 课）。下表中 n 是输入长度，k、r 是每组取几个，“总时间”指用 list() 全部取完。这些函数都是惰性的：不取就不算，next() 一次只做一步（组合类每步要生成一个长度为 k 的元组，所以是 O(k)）。

函数产出个数总时间额外空间注意
accumulate(xs)n（带 initial 时 n+1）O(n)O(1)前提是传入的函数（如 max）本身是 O(1)
pairwise(xs)n−1O(n)O(1)只记着上一个元素
chain(a, b, …) / chain.from_iterable各段长度之和 NO(N)O(1)不复制，只是依次遍历；比 a + b 省一次拷贝
islice(it, start, stop)stop − startO(stop)O(1)前 start 个也要一个个跳过，对 list 也不是 O(1) 跳转；list 直接用切片
combinations(xs, k)C(n, k) = n! / (k!(n−k)!)O(k · C(n, k))O(n)n=20、k=10 就有 184756 组；n 大时只适合 k 很小
permutations(xs, r)n! / (n−r)!（r 省略时为 n!）O(r · n!/(n−r)!)O(n)n! 增长极快：10! ≈ 363 万，n 超过 10 基本跑不动
product(A, B, …) / product(xs, repeat=r)|A|·|B|·…（或 nr）O(组数 × 每组长度)O(各输入长度之和)会先把每个输入整个读进内存，所以不能喂无穷迭代器
count(start)无穷每次 next O(1)O(1)一定要配 islice、takewhile 或 break，否则死循环
takewhile(pred, xs)满足条件的前缀长度 mO(m + 1)O(1)多检查的那 1 个（第一个不满足的）会被吃掉，不会再吐出来

combinations/permutations 这种产出个数随 n 急剧增长的现象叫“组合爆炸”，第 21 课回溯也要面对它：耗时由产出个数决定，换成手写回溯也省不掉，只能靠剪枝少走分支。

19. 海象运算符 :=

name := 表达式：算出表达式的值，赋给 name，同时把这个值作为整个式子的结果。常用在 while 条件里，省掉重复的一行：

lines = ["a", "b", ""]
reader = iter(lines)

# 不用海象：读一次放循环前，循环末尾再读一次
line = next(reader)
while line:
    print(line)
    line = next(reader)

# 用海象：读和判断写在一起
reader = iter(lines)
while (line := next(reader)):
    print(line)

看不惯可以不用，任何地方都能改回普通赋值。

20. 第三方库 sortedcontainers：一直有序的 list / dict

这是本项目唯一的第三方依赖（不是标准库），已经写在 pyproject.toml 里，uv run 时会自动装好。自己的项目里要用，执行 uv add sortedcontainers。

它提供三个容器，特点是插入、删除之后仍然保持排好序，而且这些操作都很快（快到什么程度、为什么能这么快，第 24 课讲完平衡树后就明白了；现在当成好用的黑盒）：

from sortedcontainers import SortedDict, SortedList, SortedSet

scores = SortedList([50, 90, 70])
scores.add(80)               # 插进去，自动放到对的位置
print(scores)                # SortedList([50, 70, 80, 90])
scores[0], scores[-1]        # (50, 90)   最小、最大
scores.remove(70)            # 删掉一个 70；不存在会抛 ValueError
scores.bisect_left(80)       # 1          80 应该插在下标几（第 6 课讲这个函数名的由来）
list(scores.irange(60, 90))  # [80, 90]   取出 60～90 之间的值（两端都包含）

prices = SortedDict({"pear": 3, "apple": 5})
list(prices)                 # ['apple', 'pear']   键始终按顺序排
prices.peekitem(0)           # ('apple', 5)        最小的键和它的值

tags = SortedSet(["b", "a", "b"])   # SortedSet(['a', 'b'])   去重 + 有序
容器像什么多出来的本事

21. 函数参数：默认值、关键字参数、仅限关键字的 *、**kwargs

def search(items, target, start=0):          # start 有默认值，可以不传
    ...

search([1, 2], 2)                  # 按位置传
search([1, 2], target=2, start=1)  # 按名字传（关键字参数），顺序可以随便


def top(items, *, key=None, reverse=False):   # 单独一个 * ：它后面的参数只能按名字传
    ...

top([3, 1], key=abs)               # 可以
top([3, 1], abs)                   # TypeError：key 必须写成 key=abs

骨架里常见 def index(items, target, *, key=None) 这种签名（第 6 课）。单独的 * 不收任何参数，只是一条分界线：逼调用者写出 key=，调用处一眼就能看懂，也不会把参数顺序传错。sorted(items, key=..., reverse=True) 本身就是这样设计的。

def log(message, **kwargs):        # **kwargs 收下所有“没有对应参数名”的关键字参数，是一个 dict
    print(message, kwargs)

log("下单", user="Ann", amount=3)   # 下单 {'user': 'Ann', 'amount': 3}

options = {"sep": "-", "end": "!\n"}
print("a", "b", **options)         # 调用时 ** 把 dict 摊开成关键字参数：打印 a-b!

默认值只在定义函数时算一次。所以别用可变对象当默认值：def add(item, bucket=[]) 会让每次调用共用同一个 list。用 None 或 () 代替（第 10 节也提过）。

自测

1. numbers = (n * n for n in range(3))，连续执行两次 sum(numbers)，结果分别是多少？ 5 和 0。生成器只能走一遍，第一次 sum 已经把它走完了。
2. 手写的字典类里，__getitem__ 找不到键时返回 None，会出什么问题？ 继承 Mapping 白送的 in 和 get 都靠 KeyError 判断“没有”。返回 None 的话，"x" in d 永远是 True，d.get("x", 0) 返回 None 而不是 0。
3. 下面的生成器为什么丢了 2 和 1？
def countdown_then_done():
    count_down(2)
    yield "done"

list(countdown_then_done())   # 只得到 ['done']
 count_down(2) 只是造了一个生成器对象就扔掉了，里面的 2、1 没有交出来。要写成 yield from count_down(2)。
4. sorted(words, key=len) 和 sorted(words, key=len()) 有什么区别？ key=len 把函数本身传进去，让 sorted 对每个元素调用它。len() 是立刻调用（而且少了参数，直接报 TypeError）。
