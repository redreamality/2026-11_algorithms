算法与数据结构

每一课：先读讲解（10 分钟），再写代码，跑测试全绿就算过关。

怎么学

  1. 读一课讲解。
  2. 打开对应的 dsa/*.py，把 raise NotImplementedError 换成你的实现。
  3. 在项目目录跑 这一课的测试（每课末尾写了命令，例如 uv run pytest tests/test_complexity.py），直到全绿。
  4. 让 agent review 你的代码，然后在 README 里打勾。

第六阶段：高频面试题型

把前面学过的结构和方法，套到面试里最常见的题型上。每课都有「怎么认出这类题」和 LeetCode 题号表。这一阶段没有单元测试，写完后运行对应的骨架文件（例如 uv run dsa/two_pointers.py），看每个例子的期望和实际是否一致。
