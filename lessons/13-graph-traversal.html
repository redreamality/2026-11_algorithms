第 13 课 · 图的表示、BFS、DFS

图就是点加连线。遍历有两种走法：BFS 像水波，一圈圈往外扩；DFS 像走迷宫，一条路走到底，走不通再回头。

实战里怎么写：一个 dict 就是图

Python 没有内置的图类型，日常也用不着：dict 就是邻接表，键是节点，值是邻居 list。节点直接用业务里的东西（用户名、URL、(行, 列) 坐标），不用编号成 0..n-1。

场景用什么代价
好友推荐、最短引荐链、爬虫限深dict + collections.deque 写 BFSO(V + E)，十来行
网格地图、连通区域、迷宫节点用 (行, 列)，邻居现算，不用先建图；list 当栈做 DFSO(格子数)
大图、要跑很多种图算法第三方库 networkx（本课不依赖）好用，但比手写慢很多
from collections import defaultdict, deque

follows = defaultdict(list)                       # 用户 -> 好友列表
for left, right in [("ann", "bob"), ("bob", "dan"), ("dan", "eve")]:
    follows[left].append(right)
    follows[right].append(left)

def degrees_of_separation(follows, source, target):
    """source 到 target 的最短引荐链；连不上返回 None。"""
    came_from = {source: None}                    # 兼当 seen：也记下是从谁那里过来的
    queue = deque([source])
    while queue:
        person = queue.popleft()
        if person == target:
            chain = []
            while person is not None:             # 顺着 came_from 倒着走回起点
                chain.append(person)
                person = came_from[person]
            return chain[::-1]
        for friend in follows.get(person, ()):
            if friend not in came_from:
                came_from[friend] = person
                queue.append(friend)
    return None

degrees_of_separation(follows, "ann", "eve")      # ['ann', 'bob', 'dan', 'eve']

完整可运行的版本（还有爬虫限深、数地图上的陆地块）在 examples/graph_in_practice.py（uv run examples/graph_in_practice.py）。下面看为什么这么写。

怎么存：邻接表 vs 邻接矩阵

同一张图 0-1, 0-2, 1-2，两种存法：

邻接表：{0: [1, 2], 1: [0, 2], 2: [0, 1]}
邻接矩阵：第 0 行 011
　　　　　第 1 行 101
　　　　　第 2 行 110 m[u][v] = 1 表示 u、v 相连
邻接表邻接矩阵
占空间O(V + E)O(V²)
u、v 是否相连O(u 的邻居数)O(1)
列出 u 的所有邻居O(u 的邻居数)O(V)

实际的图大多很稀疏（边远少于 V²），所以默认用邻接表。V 是点数，E 是边数。

BFS：用队列，一层层往外

from collections import deque

def bfs(graph, start):
    seen = {start}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        yield node                            # 生成器：调用方想停就停
        for neighbor in graph.get(node, ()):  # 不在键里的节点当作没有邻居
            if neighbor not in seen:
                seen.add(neighbor)            # 入队时就标记，免得重复入队
                queue.append(neighbor)

list(bfs(graph, "ann"))                                        # 按远近列出所有人
next(person for person in bfs(graph, "ann") if person.startswith("d"))  # 找到最近的一个就停

先出来的一定是离起点近的，所以第一次碰到某个点时走的边数，就是无权图的最短路。做成生成器的好处：只想找“最近的一个满足条件的点”时，找到就停，后面的图不用再走。

DFS：用递归（栈），走到底再回头

def dfs_recursive(graph, node, seen=None):
    seen = set() if seen is None else seen
    seen.add(node)
    yield node
    for neighbor in graph.get(node, ()):
        if neighbor not in seen:
            yield from dfs_recursive(graph, neighbor, seen)  # 先钻进去，回来再看下一个邻居

递归本身就是一个栈。图里有一条几万个点的长链时，递归会超过 Python 的递归深度（默认约 1000 层），实际项目里要用显式栈：栈里放每个点的“邻居迭代器”，栈顶取下一个没见过的邻居就往下钻，取完了就出栈（回头）。练习要求写的就是这个版本。

两种都是 O(V + E)：每个点进出一次，每条边看一到两次。

动手玩

先点 BFS，看橙色的点怎么排进队列、蓝色数字怎么一层层变大；再点 DFS，留意走到 2 之后栈怎么退回 3。也可以换个起点试试。

白色：没见过；橙色：在队列 / 栈里等着；红框：正在处理；绿色：处理完了。粗橙线是“第一次发现它”走的边。

最容易错的地方

  • BFS 在出队时才标记 seen：同一个点会被好几个邻居重复放进队列。
  • 忘了图可能不连通：只从一个点出发走不到全部。数连通块要对每个没见过的点都发起一次遍历。
  • 递归 DFS 在很长的链上会超过递归深度（Python 默认约 1000 层），所以要用显式栈。
  • 节点不在 dict 的键里（只出现在别人的邻居里）时，graph[node] 会抛 KeyError，要用 graph.get(node, ())。

练习

补全 dsa/graph.py。节点可以是任何可哈希的东西，bfs / dfs 用 yield 写成生成器。建议顺序：build_graph → bfs → dfs（显式栈）→ shortest_path（BFS 时记 came_from，返回整条路径）→ connected_components（返回每块的 set）。

自测

1. 为什么 DFS 不能用来求无权最短路？ DFS 先找到的路不一定最短，它可能绕了一大圈才碰到终点。BFS 按距离从近到远处理，第一次碰到就是最短。
2. 一张 1 万个点、每个点 5 条边的图，用邻接矩阵要多少格子？ 10⁴ × 10⁴ = 1 亿个格子，几乎全是 0。邻接表只要大约 5 万项。
3. 怎么判断一张无向图是否连通？ 从任意一个点做一次 BFS 或 DFS，看访问到的点数是否等于总点数。
