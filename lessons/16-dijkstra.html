第 16 课 · 最短路径（Dijkstra）

从起点出发，每次确定一个“离起点最近、还没确定”的点，再用它去更新邻居的距离。像水波一圈圈往外扩。

实战里怎么写：dict 存图 + heapq

地图导航、地铁换乘、网络路由、游戏寻路，都是“边上有耗时，找最快的路”。标准库没有现成的 Dijkstra，但 dict 套 dict 存图 + heapq，二三十行就写完了。

场景用什么代价
A 到 B 最快路线dict + heapq，终点一出堆就返回，记 previous 复原路线最坏 O((V + E) log V)，通常远少于整图
“10 分钟内能到哪些站”写成按远近 yield 的生成器 + itertools.takewhile只算预算以内的部分
所有边权都相同不用堆，BFS（第 13 课）就够O(V + E)
超大路网、A*、K 短路networkx 或专门的路网引擎（本课不依赖）—
import heapq
from itertools import count

network = {                                  # 站 -> {邻站: 分钟}
    "静安寺": {"南京西路": 2},
    "南京西路": {"静安寺": 2, "人民广场": 2},
    "人民广场": {"南京西路": 2, "陆家嘴": 6},
    "陆家嘴": {"人民广场": 6},
}

def plan_route(network, origin, destination):
    best_minutes = {origin: 0}
    previous = {}
    finished = set()
    sequence = count()                       # 距离相同时按入堆顺序，不去比较站名
    heap = [(0, next(sequence), origin)]
    while heap:
        minutes, _, station = heapq.heappop(heap)
        if station in finished:              # 过期记录，跳过
            continue
        finished.add(station)
        if station == destination:           # 终点确定了，立刻返回
            route = [station]
            while route[-1] != origin:
                route.append(previous[route[-1]])
            return minutes, route[::-1]
        for neighbor, segment_minutes in network.get(station, {}).items():
            arrival = minutes + segment_minutes
            if arrival < best_minutes.get(neighbor, float("inf")):
                best_minutes[neighbor] = arrival
                previous[neighbor] = station
                heapq.heappush(heap, (arrival, next(sequence), neighbor))
    return None                              # 到不了

plan_route(network, "静安寺", "陆家嘴")     # (10, ['静安寺', '南京西路', '人民广场', '陆家嘴'])

完整可运行的版本（路线规划、“10 分钟内能到哪些站”）在 examples/dijkstra_in_practice.py（uv run examples/dijkstra_in_practice.py）。下面看为什么这样做是对的。

问题长什么样

图的边上有权重（路长、耗时）。求起点到每个点的最短距离。BFS 只能数“几步”，权重不一样就不灵了。

A—4—B 直接走是 4； A—1—C—2—B 绕一下只要 3

两样东西：dist 表 + 最小堆

  • dist[v]：目前已知的起点到 v 的最短距离，起点为 0，其余先记 ∞。
  • 最小堆（第 12 课）：存 (距离, 点)，每次 O(log V) 取出最近的那个。
import heapq

def shortest_distances(graph, source):       # graph: {点: {邻点: 权重}}
    distances = {source: 0}                  # 没出现的点就是“目前还到不了”
    heap = [(0, source)]
    while heap:
        distance, node = heapq.heappop(heap)
        if distance > distances[node]:       # 过期的旧记录，跳过
            continue
        for neighbor, weight in graph.get(node, {}).items():
            candidate = distance + weight
            if candidate < distances.get(neighbor, float("inf")):   # 松弛：经过 node 去 neighbor 更近
                distances[neighbor] = candidate
                heapq.heappush(heap, (candidate, neighbor))
    return distances

松弛就是一句话：“经过 u 绕过去，比现在记着的更短吗？更短就改。”

heapq 没法修改堆里已有的元素，所以变短时直接再塞一条新记录，旧的取出来时跳过就行。

为什么取出来就“确定”了

堆顶的 u 是剩下的点里最近的。别的路要先到一个更远的点，再走非负的边，只会更长，不可能反超。

所以负权边不能用：一条 −5 的边能让“更远的点”绕回来反超，已确定的答案就错了。负权要用 Bellman-Ford。

复杂度

步骤代价
每条边最多松弛一次，可能进堆一次E 次 × O(log V)
出堆最多 E 次 × O(log V)
合计O((V + E) log V)

动手玩

点从 A 出发。橙色粗线是正在松弛、成功变短的边，灰色虚线是“试了但没变短”。注意 B：先被记成 4，经过 C 又改成 3，于是堆里留下一条过期的 (4, B)。

最容易错的地方

  • 忘了跳过过期记录：不出错，但会白白重复松弛。
  • 不可达的点不要写成 0 或 -1：本课约定干脆不放进结果，调用方用 distances.get(node, math.inf)。
  • 求路径时要额外记 previous[neighbor] = node，最后从终点倒着走回起点再反转。
  • 堆里只放 (距离, 节点) 时，距离相同就会去比较节点；节点是没法比大小的东西时直接抛 TypeError。中间加一个递增的序号就好。

练习

补全 dsa/dijkstra.py。图是 dict 套 dict，可以用 heapq。建议顺序：walk_by_distance（生成器，按远近 yield (节点, 距离)，每个点一次）→ shortest_paths（一次算出所有距离和 previous 表）→ shortest_path（终点一出堆就返回整条路径，测试会检查它确实提前停了）。

自测

1. 所有边权都是 1 时，Dijkstra 退化成什么？ BFS。堆每次取出的就是按层的顺序，用普通队列就够了，O(V + E)。
2. 只想要 s 到 t 的距离，能提前结束吗？ 能。t 从堆里取出（被确定）的那一刻就可以返回。
3. 把所有边权加上同一个大数，消掉负权，再跑 Dijkstra 行不行？ 不行。边多的路径被加得多，最短路可能变了。
