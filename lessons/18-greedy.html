第 18 课 · 贪心

贪心就是每一步都拿眼下最好的，拿了不反悔。写起来最短，但只有在“局部最好能推出全局最好”时才对。

实战里怎么写：sorted + 一次遍历

贪心在业务代码里不用调任何库，几乎都是“按某个关键字 sorted，再扫一遍，能要就要”。难的不是写，而是选对排序关键字、确认贪心是对的。

场景怎么写代价
一间会议室尽量多接预约按结束时间排序，不冲突就接O(n log n)
合并日历忙碌时段、算空闲按开始时间排序，能接上就延长O(n log n)
收银找零（标准币制）面值从大到小，divmod 算张数O(面值种数)
任意面值找零、预算内选东西贪心不对，改用 DP（第 19、20 课）O(金额 × 种数)
from operator import attrgetter

def schedule_one_room(bookings: list[Booking]) -> list[Booking]:
    accepted = []
    for booking in sorted(bookings, key=attrgetter("end")):
        if not accepted or accepted[-1].end <= booking.start:
            accepted.append(booking)
    return accepted

def make_change_in_cents(amount, denominations=(10000, 5000, 2000, 1000, 500, 100, 50, 10, 1)):
    change, remaining = Counter(), amount
    for value in sorted(denominations, reverse=True):
        count, remaining = divmod(remaining, value)   # 一次算出这种面值拿几张
        if count:
            change[value] = count
    if remaining:
        raise ValueError(f"凑不出 {amount} 分")
    return change

完整可运行的版本（会议室、空闲时段、找零）在 examples/greedy_in_practice.py（uv run examples/greedy_in_practice.py）。下面讲这些写法为什么对、什么时候会错。

一个类比

一天想多参加几个活动：先挑最早结束的那个，剩下的时间最多，后面能塞进去的也最多。然后在不冲突的里面再挑最早结束的……这就是贪心。

贪心会翻车：硬币 [1, 3, 4] 凑 6

贪心：4113 枚 　最优：332 枚

先拿最大的 4，看着赚了，后面只能用 1 补。人民币、美元这种标准币制贪心才是对的；任意面值要用动态规划（第 19、20 课）。

所以用贪心之前要问一句：“先拿眼下最好的，会不会堵死更好的路？”说不清楚就先找反例。

三个经典例子

问题贪心策略复杂度
活动选择：最多几个不重叠按结束时间排序，能选就选O(n log n)
合并区间按起点排序，能接上就延长最后一段O(n log n)
跳跃游戏：能否跳到最后从左往右扫，维护“最远能到哪”O(n)
def select_activities(intervals: list[tuple[int, int]]) -> list[tuple[int, int]]:
    chosen = []
    for start, end in sorted(intervals, key=lambda interval: interval[1]):
        if not chosen or chosen[-1][1] <= start:   # 不和上一个选中的重叠
            chosen.append((start, end))
    return chosen

为什么按结束时间是对的？任何一个最优解，把它的第一个活动换成“最早结束的那个”，不会和后面冲突，个数不变。换完再对剩下的部分重复这个论证。

动手玩

先点按结束时间选，看红线（上一个选中活动的结束时间）怎么往右推；再点按开始时间选，看最长的 C 怎么把后面挤掉。

最容易错的三个地方

  • 排序的关键字选错：活动选择按结束时间，合并区间按起点。
  • 端点相接算不算重叠：本课活动是 [s, e)，5 结束、5 开始不冲突；合并区间是闭区间，(1,3) 和 (3,5) 要合并。
  • 跳跃游戏里，走到一个下标前先检查它是不是已经超出“最远能到”。

自测

1. 活动选择按“最短的先选”行不行？ 不行。反例：(0,5)、(4,6)、(5,10)。最短的 (4,6) 和另外两个都冲突，只能选 1 个；按结束时间能选 (0,5)、(5,10) 两个。
2. 贪心和动态规划的区别？ 贪心每步只看一个选择，拿了不回头；DP 把每个选择都试一遍、记下子问题的答案。贪心对的时候更快，但要先证明它对。
3. 跳跃游戏 [3, 2, 1, 0, 4] 卡在哪？ 从 0、1、2、3 出发最远都只能到下标 3，而 nums[3] = 0，走到下标 4 时已经超出了最远能到的范围。
