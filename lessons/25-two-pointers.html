第 25 课 · 双指针

双指针不是一道题的名字，而是一种走数组或链表的方法：让两个下标各自只向前走，每一步都排除一批不可能的情况。

先理解 两个母模板 如何识别 逐题套用 扩展题单 练习与自测

开始前要会：Python 的下标、while、for、解包与交换、list.sort()；前面的课 —— 第 8 课 · 归并排序（合并有序数据）、第 12 课 · 堆（见过 heapq.merge）。

先理解：两个下标为什么能变快

假设数组已经有序，要找两个数之和等于 target。暴力做法会枚举所有下标对，时间是 O(n²)。双指针先看两端：

target = 9： 271115 2 + 15 = 17，太大，15 不可能留下
　　　　　　 271115 2 + 11 = 13，还是太大，11 不可能留下
　　　　　　 271115 2 + 7 = 9，找到答案

关键不是“两个下标一起动”，而是每次移动前都能证明：被丢掉的那一侧，和候选范围里的任何数都无法组成更好的答案。这个证明成立时，原来的两层枚举就可以压成一层。

先记两个母模板

双指针常见有两种走法。先理解它们的职责，后面四道题只是在模板里替换“当前状态”和“移动规则”。

走法两个指针的位置适合解决
对撞指针left 从左边来，right 从右边来，向中间靠拢有序数组找一对、从两端比较、计算两端形成的结果
快慢指针fast 扫描所有元素，slow 维护下一个有效位置原地删除、移动、去重；链表找中点和环

母模板 A：对撞

left, right = 0, len(items) - 1
while left < right:
    state = 根据两端计算当前状态
    if 左边已经不可能：
        left += 1
    elif 右边已经不可能：
        right -= 1
    else：
        记录答案，或两边都向内

母模板 B：快慢

slow = 0
for fast in range(len(items)):
    if items[fast] 应该保留：
        把 items[fast] 放到 slow
        slow += 1
返回 slow，或按 slow 截断

统一检查句：“我现在跳过的这一批位置，为什么不可能藏着答案？”能回答这句，才能移动指针；两个指针都不回头，时间才是 O(n)。

四道主讲题的变化

题目套哪个模板当前状态变化点
两数之和 II对撞两数之和与 target 的关系和小移左，和大移右，等于就返回
盛最多水对撞当前面积先更新最大值，再丢掉较矮的一边
三数之和固定一个数 + 对撞三个数的总和找到后两边都移动，并跳过重复值
移动零快慢fast 指向的值是否有效有效值写到 slow，无效值只让 fast 继续

怎么识别双指针题

  • 数组有序，要找两个数、三个数满足和或差的条件：先想对撞指针。
  • 题目要从两端向中间比较：回文、反转、容器面积，先想对撞指针。
  • 要求原地修改、保持顺序、额外空间 O(1)：先想快慢指针。
  • 链表要找中点、倒数第 k 个、判断环：先想快慢指针，只是 fast 的步长不同。
  • 暴力是在枚举所有 (i, j) 对，而数组有序或候选可以被排除：检查能否让每个指针只走一遍。

题 1：两数之和 II

题意：数组 numbers 已经从小到大排序，找两个不同位置的数，使和等于 target。例子：[2, 7, 11, 15] 和 target = 9 返回 [0, 1]。

令 left 指向最小数、right 指向最大数。当前和太小，说明左边这个数需要换一个更大的搭档；当前和太大，说明右边这个数需要换一个更小的搭档。

套母模板 A：状态是当前两数之和；移动规则就是“和小移 left，和大移 right”；找到后可以直接结束。

left, right = 0, len(numbers) - 1
while left < right:
    pair_sum = numbers[left] + numbers[right]
    if pair_sum == target:
        return [left, right]
    if pair_sum < target:
        left += 1
    else:
        right -= 1

复杂度：时间 O(n)，额外空间 O(1)。

题 2：盛最多水的容器

题意：heights[i] 是第 i 根竖线的高度，选择两根竖线，面积是 min(heights[left], heights[right]) * (right - left)，求最大面积。

两端开始时宽度最大。每次移动后宽度都会变小，所以必须让高度有机会变大：移动较矮的一边。较矮的一边已经和最远的搭档算过了，换更近的搭档时宽度变小，高度又不可能超过它自己，继续保留它没有意义。

和题 1 比较：left、right 和循环条件完全不变；只把状态换成面积，把“找到就返回”换成“更新 best”，再把移动规则换成“移动较矮的一边”。

left, right = 0, len(heights) - 1
best_area = 0
while left < right:
    water_height = min(heights[left], heights[right])
    best_area = max(best_area, water_height * (right - left))
    if heights[left] < heights[right]:
        left += 1
    else:
        right -= 1

复杂度：时间 O(n)，额外空间 O(1)。

为什么只算很少的组合

把每一对竖线看成一个格子，暴力要检查全部格子。双指针每算一格，就能把较矮一边后面的整行或整列排除。下面的表格把“算过”和“被排除”的组合画出来。

题 3：三数之和

题意：在无序数组中找出所有和为 0 的三元组，结果不能重复。例子：[-1, 0, 1, 2, -1, -4] 返回 [[-1, -1, 2], [-1, 0, 1]]。

先排序。然后固定第一个数 numbers[first_index]，剩余任务就变成：在它右边找两个数，使它们的和等于 -numbers[first_index]。这正是题 1 的对撞模板，只是找到一组后还要继续找。

和题 1 比较：外层多了一个固定点；内层 while left < right 的移动逻辑相同。新增的只有三件事：排序、固定点去重、答案后的两边去重。

numbers.sort()
triplets = []
for first_index in range(len(numbers) - 2):
    if first_index > 0 and numbers[first_index] == numbers[first_index - 1]:
        continue
    left, right = first_index + 1, len(numbers) - 1
    while left < right:
        total = numbers[first_index] + numbers[left] + numbers[right]
        if total < 0:
            left += 1
        elif total > 0:
            right -= 1
        else:
            triplets.append([numbers[first_index], numbers[left], numbers[right]])
            while left < right and numbers[left] == numbers[left + 1]:
                left += 1
            while left < right and numbers[right] == numbers[right - 1]:
                right -= 1
            left += 1
            right -= 1
return triplets

复杂度：排序 O(n log n)，外层固定点加内层对撞共 O(n²)，除结果列表外额外空间 O(1)。

题 4：移动零

题意：原地把所有 0 移到末尾，非零元素保持原来的顺序。例子：[0, 1, 0, 3, 12] 变成 [1, 3, 12, 0, 0]。

这里不需要从两端夹逼。fast 从头扫到尾，slow 只负责记住“下一个非零值应该放在哪里”。遇到 0 时 fast 继续；遇到非零值时，把它交换到 slow，再让 slow 前进。

套母模板 B：判断条件是“numbers[fast] != 0”。把条件改成“numbers[fast] != val”就是移除元素；改成“当前值与已写入的最后一个值不同”就是有序数组去重。

slow = 0
for fast in range(len(numbers)):
    if numbers[fast] != 0:
        numbers[slow], numbers[fast] = numbers[fast], numbers[slow]
        slow += 1

不变量是：[0, slow) 已经放好了非零数，且顺序正确；[slow, fast) 是已经遇到的 0。fast 扫完时，数组自然变成目标形状。

复杂度：时间 O(n)，额外空间 O(1)。

模板继续变形：滑动窗口

下一课的滑动窗口也是两个同方向的指针。区别在于：移动零里的 slow 是“写入位置”，滑动窗口里的 slow 是“窗口左边界”，fast 是“窗口右边界”。窗口还需要维护一份状态，例如字符集合、字符计数或窗口和。

写法slow 的含义fast 的含义slow 什么时候前进
移动零下一个有效值的写入位置正在扫描的元素fast 找到有效值时
无重复最长子串窗口左边界窗口右边界窗口出现重复时，直到重新合法
最短覆盖窗口窗口左边界窗口右边界窗口已经满足覆盖条件时，尽量缩短

因此可以这样记：对撞指针从两端排除候选；快慢指针维护已经处理好的前缀；滑动窗口把这个前缀换成一个连续区间。

在真实代码里哪里会遇到

业务代码很少直接写“对撞指针找两数之和”，但双指针经常藏在数据处理里：

场景做法复杂度
合并两份已排序日志heapq.merge(a, b)；每份输入各有一个读取位置O(n + m)，可以边读边合并
对账，找两边都有或只有一边的 ID同向扫描两份有序列表，较小的一边前进O(n + m)
按条件原地删除快慢指针，最后只保留前 slow 个位置O(n)，额外空间 O(1)
def reconcile(ledger_ids: list[int], bank_ids: list[int]):
    matched, ledger_only, bank_only = [], [], []
    ledger_index = bank_index = 0
    while ledger_index < len(ledger_ids) and bank_index < len(bank_ids):
        ledger_id, bank_id = ledger_ids[ledger_index], bank_ids[bank_index]
        if ledger_id == bank_id:
            matched.append(ledger_id)
            ledger_index += 1
            bank_index += 1
        elif ledger_id < bank_id:
            ledger_only.append(ledger_id)
            ledger_index += 1
        else:
            bank_only.append(bank_id)
            bank_index += 1
    ledger_only.extend(ledger_ids[ledger_index:])
    bank_only.extend(bank_ids[bank_index:])
    return matched, ledger_only, bank_only

扩展题：删除有序数组中的重复项（26）

数组已排序，原地删除重复值，使每个值只保留一次，返回不同值的个数。slow 指向下一个应该写入的位置，只有当前值和前一个已保留值不同才写入。

扩展题：移除元素（27）

原地移除所有等于 val 的元素，返回剩余个数。顺序可以改变时，也可以让 slow 从前面、另一个指针从后面配合交换；顺序需要保持时直接套移动零的快慢模板。

扩展题：验证回文串（125）

忽略非字母数字并统一大小写后，从字符串两端向中间比较。两端相等就同时移动，否则返回 false。

扩展题：有序数组的平方（977）

原数组有序，但平方后最大的值一定来自两端。比较两端绝对值，把较大的平方从结果数组末尾向前填写。

扩展题：最接近的三数之和（16）

排序并固定第一个数，内层仍然是两数之和的对撞模板。每轮用当前总和更新与 target 最接近的答案。

扩展题：链表的中间结点（876）

slow 每次走一步，fast 每次走两步。fast 到尾部时，slow 位于中间；偶数个节点时，这种写法返回第二个中间节点。

扩展题：环形链表（141）

slow 每次一步，fast 每次两步。有环时 fast 会追上 slow；fast 到达空节点时说明没有环。

扩展题：接雨水（42）

从两端开始维护左右最高柱子，哪一边的最高柱子更低，就处理哪一边，因为这一边的水量已经由较低的边界决定。

最容易错的地方

  • 找两个不同位置时写成 left <= right，可能把同一个元素用两次，应写 left < right。
  • 盛水题移动较高的一边。宽度变小后，较矮边仍然限制水高，移动高边没有给高度增加机会。
  • 三数之和忘记排序，或者找到答案后没有跳过重复值。
  • 移动零遇到 0 就调用 remove 和 append，每次移动都可能复制大量元素，最坏会变成 O(n²)。
  • 只背“两个指针”，却说不清被跳过的候选为什么不可能。没有这个证明，就不能安全移动。

练习与自测

补全 dsa/two_pointers.py，建议顺序：two_sum_sorted → max_water_area → move_zeroes → three_sum。运行：

uv run dsa/two_pointers.py
1. 两数之和 II 为什么要求数组有序？

因为“和太小就向右找更大的数、和太大就向左找更小的数”依赖有序。无序时应考虑哈希表。

2. 盛水题两根竖线一样高时移动哪根？

哪根都可以。两根都已经和最远搭档算过，换更近的搭档只会让宽度变小。

3. 快慢指针如何找链表中点？

slow 一步、fast 两步。fast 到尾部时，slow 走过的距离约是一半。
